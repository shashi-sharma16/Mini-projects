# Password Strength Checker and Suggestion Tool

A simple Python program that checks the strength of a user-entered password and provides feedback on how to improve it. If the password is weak, the program also generates a strong password suggestion.

## Features

* Checks password length and complexity
* Validates the presence of uppercase and lowercase letters
* Detects digits and special characters
* Displays specific suggestions for improving weak passwords
* Generates a strong random password recommendation
* Hides password input for better security

## Technologies Used

* Python
* Random Module
* Getpass Module
* String Module
