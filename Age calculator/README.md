# Age Calculator

A simple Python program that calculates approximately how many days, hours, and minutes a person has been alive based on their age in years.

## Features

- Calculates age in days, hours, and minutes
- Uses an average year length of 365.25 days
- Formats large numbers with commas for readability
- Handles invalid input gracefully
- Allows multiple calculations in a single run

## Technology Used

- Python

## Example Output

Enter your age in years: 20

You are approx:

- 7,305 days old
- 175,320 hours old
- 10,519,200 minutes old
