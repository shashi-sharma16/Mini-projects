# CSV-Powered Contact Book

A terminal-based Contact Book built in Python that stores and manages contacts using a CSV file. This project demonstrates data handling, file operations, and basic contact management through a simple command-line interface.

## Features

* Add new contacts
* View all contacts
* Search contacts by name
* Case-insensitive partial name search
* Prevent duplicate contact names
* Automatic CSV file creation
* Persistent data storage

## Technologies Used

* Python
* CSV Module
* OS Module

## Concepts Practiced

* File Handling
* CSV Data Management
* Data Validation
* Search Operations
* CLI Development

## Contact Details Stored

* Name
* Phone Number
* Email Address

## Learning Outcomes

This project helped me practice working with CSV files, managing persistent data, validating user input, and building an interactive command-line application in Python.
