# JSON to CSV Converter

A simple Python utility that converts JSON data into CSV format.

## Features

* Reads data from a JSON file
* Converts JSON records into CSV format
* Automatically generates CSV headers from JSON keys
* Handles missing files and invalid JSON data
* Displays conversion status and record count

## Technologies Used

* Python
* JSON Module
* CSV Module
* OS Module

## Sample JSON Format

```json
[
    {
        "id": 1,
        "name": "John Doe",
        "email": "john@example.com"
    }
]
```
