# 🎬 Personal Movie Tracker

A simple Python CLI application that allows users to manage their personal movie collection using JSON-based data storage.

## Features

* Add movies with genre and rating
* Prevent duplicate movie entries
* View all saved movies
* Search movies by title or genre
* Persistent data storage using JSON

## Technologies Used

* Python
* JSON
* File Handling

## Example

```text
🍿 My MovieDB

1. Add Movie
2. View All Movies
3. Search Movie
4. Exit

Choose an option (1-4): 1
Enter the movie name: interstellar
Genre: sci-fi
Enter rating (0-10): 9.5

Movie added ✅
```
