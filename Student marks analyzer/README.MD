# Student Marks Analyzer

## Overview

A Python-based project that collects student names and marks, then analyzes the data to generate useful insights such as average marks, highest score, lowest score, and a detailed marks report.

## Features

* Store student names and marks
* Prevent duplicate entries
* Validate user input
* Calculate average marks
* Identify top and bottom performers
* Display a detailed marks summary

## Technologies Used

* Python

## Concepts Covered

* Functions
* Dictionaries
* Loops
* Conditional Statements
* Exception Handling
* List Comprehensions
