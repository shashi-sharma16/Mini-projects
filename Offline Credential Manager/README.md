# Terminal Based Credential Manager

A simple terminal-based credential management application built with Python. It allows users to securely store and view website login credentials while saving data locally in an encoded text file.

## Features

* Add website credentials
* View saved credentials
* Password strength checker
* Stores credentials using Base64 encoding
* Persistent storage using a text file
* Menu-driven command-line interface

## Technologies Used

* Python
* Base64 Module
* OS Module
