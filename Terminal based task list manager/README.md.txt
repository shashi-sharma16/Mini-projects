# Terminal Based Task List Manager

A simple terminal-based task management application built with Python. It allows users to create, view, complete, and delete tasks while storing data locally in a text file for persistence.

## Features

* Add new tasks
* View all saved tasks
* Mark tasks as completed
* Delete tasks
* Persistent task storage using a text file
* Displays task completion status with checkboxes

## Technologies Used

* Python
* OS Module
