# Secret Message Encryptor & Decryptor

A simple Python program that uses the Caesar Cipher technique to encrypt and decrypt messages using a user-provided key.

## Features

* Encrypts text messages using a shift key
* Decrypts encrypted messages back to the original text
* Preserves spaces, punctuation, and special characters
* Supports both uppercase and lowercase letters
* Handles invalid key inputs gracefully

## Technologies Used

* Python
