# Countdown Timer

A simple Python-based countdown timer that takes time in seconds from the user and displays the remaining time in **MM:SS** format until the countdown reaches zero.

## Features

* Accepts countdown duration in seconds
* Validates user input and handles errors
* Displays remaining time in real-time
* Formats time as minutes and seconds (MM:SS)
* Notifies the user when the timer ends

## Technologies Used

* Python
* time module
