# Terminal Based Offline Notes Locker

A simple terminal-based secure notes application built with Python. It allows users to create, store, search, and view encrypted notes while saving data locally in a JSON file protected with Fernet encryption.

## Features

* Add encrypted notes
* List saved notes
* View and decrypt notes
* Search notes by title
* Automatic timestamp for each note
* Secure storage using Fernet encryption
* Persistent storage using a JSON file
* Automatic encryption key generation
* Menu-driven command-line interface

## Technologies Used

* Python
* JSON Module
* OS Module
* Cryptography (Fernet)
* Datetime Module
